# 不高山上隐私政策

更新及生效日期：2026 年 9 月 18 日

不高山上（Bugaoshan）是 The-Brotherhood-of-SCU 维护的非官方开源校园助手，与四川大学没有官方隶属关系。本政策说明应用本身如何处理信息，以及使用学校服务、外部网页时的数据流向。隐私联系邮箱：**wjl@wjlo.cc**。

## 您可以如何使用应用

您可以不登录校园账号，使用本地课表管理等不需要身份认证的功能。成绩、教务课表导入、报修、请假、第二课堂等功能需要相应校园服务的账号与权限。本应用不注册独立的校园账号，也不能代学校创建或注销统一身份认证账号。

## 处理的信息与目的

| 使用场景 | 处理的信息 | 数据流向及用途 |
|---|---|---|
| 本地课表、主题与背景 | 手动录入的课程、课表设置、您选择的背景图片 | 在本机保存和显示；iOS 课表小组件通过本机 App Group 读取课表 |
| 校园登录 | 学号或登录名、密码、验证码、认证凭证与登录状态 | 发送至学校认证及相关业务系统，用于验证身份、建立会话；选择记住密码时通过系统安全存储保存凭据 |
| 校园数据查询 | 姓名、学号、学院、课表、成绩、考试、培养方案、校园服务余额、体测结果和第二课堂记录等 | 从相应学校系统获取，用于向您显示查询结果；部分结果在本机缓存，不自动上传至开发团队的服务器 |
| 在线报修 | 联系姓名、电话、地址、故障描述、您提交的照片、预约时间及评价 | 发送至学校智慧后勤系统，用于保存常用地址、建立工单、安排处理和接收评价 |
| 请假及其他办事表单 | 页面显示的身份资料、电话、去向地址、离返校时间、事由及主动上传的证明图片 | 发送至学校办事系统，用于审批和保存业务记录；具体字段以您办理的事项表单为准，请勿提交无关个人信息 |
| 第二课堂 | 您选择的活动、报名或取消操作、成绩单记录及导出时填写的收件邮箱 | 发送至学校第二课堂系统，完成报名、查询和成绩单邮件导出 |
| 校园网设备管理 | 您填写的设备 MAC 地址、绑定期限、账号对应的设备与操作信息 | 发送至学校网络服务系统，完成设备绑定、查询或下线操作；本应用不会为广告目的自动采集设备广告标识符 |
| 系统日历与分享 | 您选择导出的课表、考表、文件或图片 | 由您授权后写入系统日历，或交给您选择的分享接收方；所选日历账户可能根据系统设置同步数据 |
| 意见反馈与故障诊断 | 您主动提供的反馈内容、联系方式、截图或导出的诊断日志 | 通过您选择的邮件、GitHub 等渠道发送给对应接收方，用于处理问题；本机日志不会自动上传给开发团队 |

报修、请假、活动报名、设备绑定等操作会在相应服务器产生记录。它们并非仅在本机处理，也不会因卸载本应用而自动从服务器删除。请假事由或您选择的证明材料可能包含健康等敏感信息，请仅按实际业务需要提交。

## 网络服务与第三方页面

校园业务主要与四川大学相关域名通信，包括 `id.scu.edu.cn`、`zhjw.scu.edu.cn`、`wfw.scu.edu.cn`、`payapp.scu.edu.cn`、`dekt.scu.edu.cn`、`pead.scu.edu.cn`、`service.scu.edu.cn`、`zhhq.scu.edu.cn` 及相应通知站点。

iOS 版的“志愿四川”入口在系统浏览器打开 `zysc.scyol.com`，您在该网站注册、登录或报名时，由该网站运营方按其政策处理信息。其他平台可能通过内嵌网页显示该服务。学校通知及其他网页同样可能使用 Cookie、网站统计或第三方资源；请同时阅读相应网站的隐私说明。本应用不把校园账号密码自动传给志愿四川。

部分学校通知网页包含访问及点击统计，会向对应网站发送页面或新闻标识、来源页面、屏幕尺寸和链接点击等信息，用于网站访问统计。网站同时能够接收正常网络连接信息。我们无法代网站运营方承诺这些记录的保存期限或匿名化方式，也不能保证它们无法与账号、设备或其他记录关联。

开启在线字体时，应用使用 Google Fonts 获取字体；您可在字体设置中关闭。应用还会按功能需要向 GitHub 或对应代理、镜像服务请求更新信息和公开校历资源。上述资源请求不会附带本应用保存的校园密码、认证凭证或校园业务缓存。资源服务器仍能接收建立连接所需的 IP 地址、请求路径等网络信息，其处理规则由相应服务提供方说明。

## 权限与您的选择

- **照片**：您主动选择图片用于课表背景、报修或办事证明。背景图片用于本机显示；报修或办事页面的图片会在您执行相应上传或提交操作时发送到该业务系统。保存图片到相册需系统允许。
- **日历**：用于显示可写日历并将选中的课表或考表写入系统日历。应用不会将您系统日历中的其他事件自动上传给开发团队。
- **文件与分享**：您可导入、导出或分享课表、附件和日志；接收应用及云盘的后续处理由您所选择的服务负责。

拒绝相关权限只会影响需要该权限的功能。您可通过系统设置管理权限，并在应用内关闭记住密码或在线字体等选项。

## 保存、保护与删除

开发团队没有提供校园数据云同步服务。课表、设置、下载附件和部分查询缓存由应用在本机保存；登录凭据使用 Flutter Secure Storage 对接系统安全存储。应用内的诊断日志采用本机缓冲并进行常见凭据脱敏，但用户主动分享前仍应检查内容。

本应用原生代码未集成广告投放或行为分析 SDK，未实现跨应用广告追踪。这一说明不替代第三方网站自身的隐私说明。网络接收方、系统备份和您主动选择的分享服务具有各自的数据处理规则。

大多数校园服务使用 HTTPS；教务系统 `zhjw.scu.edu.cn` 使用 HTTP，其会话凭证在该链路不受 HTTPS 保护。请谨慎选择网络环境，并以学校官方系统确认选课、考试等重要事务。

您可以通过以下方式管理数据：

1. 在应用设置中使用“清除全部数据”，重置主要应用设置、删除课表及保存的登录用户名与密码，并退出校园登录。这个按钮不擦除所有本机文件：下载附件、背景图片文件、历史余额记录、日志、第三方网页缓存及个别安全存储偏好等可能保留。请按数据类型另行删除下载文件，或使用系统的应用数据管理与卸载功能；也可单独退出登录或删除课表。
2. 在系统日历、照片、文件或接收应用中，分别删除已导出的内容。退出登录或卸载不撤回已发送、已导出或已分享的内容。
3. 若需更正或删除学校账户、工单、请假、活动报名、网络设备绑定等后台记录，请使用该服务提供的管理入口或联系其运营方。开发团队不控制这些服务器，不能代其承诺保存期限、注销结果或删除全部业务记录。
4. 如需处理已主动发送给维护者的反馈材料，或咨询本应用的数据处理，请联系 **wjl@wjlo.cc**。请提供足以定位相关反馈的说明，避免发送密码、验证码或完整认证凭证。

系统安全存储、备份和第三方网页缓存的清理受操作系统及对应服务规则影响，卸载应用不能保证这些位置的所有副本同时删除。

## 未成年人及政策更新

本应用面向有校园服务使用资格的学生，不以儿童为目标用户。未成年用户应在监护人指导下了解数据处理方式，并仅提交使用相应校园服务所需的信息。

本政策会随应用功能和数据处理方式更新。涉及重大变化时，应用将通过更新后的协议提示您重新阅读确认。您可通过公开项目源代码查阅历史版本。
