# ADR-0006：不引入“小组课表重叠（Group Shadow）”

- 状态：已拒绝
- 决策日期：2026-09-08

## 背景

Issue #283 提议增加“小组课表”能力，允许同组成员课表重叠查看（Group Shadow），并要求评估 UI 布局与实现方案。

维护者评估结论为：该需求使用面较小，但涉及课程数据模型、课表渲染、导入/同步与交互流程的跨模块改动，整体复杂度和维护成本较高。

## 决策

当前版本**不引入**“小组课表重叠（Group Shadow）”功能，不进入实现阶段。

## 理由

1. **需求优先级不足**：目标用户面较小，短期收益有限。
2. **改动范围过大**：会显著扩大课程域模型与课表页面复杂度，影响现有稳定功能迭代节奏。
3. **维护成本较高**：功能上线后需长期承担多课表协同展示、冲突显示与兼容逻辑维护。

## 后果

- 课表能力保持当前单用户课表视图与现有导入/导出流程，不新增小组重叠视图入口。
- 若后续出现明确、持续且高优先级的同类需求，再以新 RFC 重新评估。
