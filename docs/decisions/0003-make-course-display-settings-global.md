# ADR-0003：课表显示偏好归属全局设置域

- 状态：已接受并实施
- 决策日期：2026-07-05
- 实施提交：`7d0aefa`
- 发布版本：`2.2.0`

## 背景

“显示教师”“显示教室”“显示周末”和“显示非本周课程”曾同时出现在全局课程表样式页和单课表设置页，并存入 `ScheduleConfig`。这造成三个问题：

1. 用户在全局样式页修改设置，切换课表后结果变化。
2. 同一开关在两个页面重复出现，所有权不清楚。
3. 样式页预览展示全局视觉效果，开关却修改当前课表数据。

## 决策

四个显示偏好属于全局视觉设置：

```text
showTeacherName
showLocation
showWeekend
showNonCurrentWeekCourses
```

具体规则：

1. 持久化所有权归 `AppConfigProvider`，使用 `SharedPreferences`。
2. `ScheduleConfig` 不保存、复制或导出这四个字段。
3. 四个开关只在全局课程表样式页编辑。
4. 切换或新建课表不改变用户的持久化视觉偏好；导入行为见下方“未决边界”。
5. 特定视图可以通过显式参数做临时覆盖，例如班级课表详情强制展示周末；局部覆盖不能写回全局值。
6. `grid_logic` 等纯逻辑函数继续接收解析后的参数，不直接从 GetIt 读取设置，以保留测试边界。

默认值为：

| 设置 | 默认值 |
|---|---|
| 显示教师 | `true` |
| 显示教室 | `true` |
| 显示周末 | `false` |
| 显示非本周课程 | `true` |

## 兼容性

- 旧 `ScheduleConfig` JSON 中的额外显示字段由现行手写 `fromJson` 忽略，因此旧课表仍可读取。
- 再次保存课表时，现行 `toJson` 不再输出这些字段。
- 旧课表中的自定义显示值没有迁移到全局设置；新 SharedPreferences key 缺失时使用上述默认值。
- 新导出的共享课表不携带显示偏好，导入旧共享 JSON 时也忽略这些字段。

## 后果

正面影响：

- 显示设置的页面、存储和生命周期一致。
- 所有课表共享用户视觉偏好，切换课表不会产生意外变化。
- `ScheduleConfig` 只保留学期、节次和时段等课表域数据。

代价与约束：

- 不再支持每张课表持久化不同显示偏好。
- 需要显示差异的功能必须使用显式、非持久化的视图参数。
- 旧版本的单课表显示选择升级后回落到全局默认值。

## 未决边界

`ImportSchedulePage._parseJwxtData` 当前会根据导入结果修改全局 `showWeekend`。本 ADR 只确定该值由全局设置持有，没有决定导入器是否应主动修改用户偏好。后续调整这一行为前，应先明确产品策略，并覆盖取消导入、失败导入和批量导入的情况。
