- iOS 26 and later support the native Liquid Glass bottom navigation, switches and some action buttons; the schedule, campus and profile content can scroll behind the bottom bar, while older systems and other platforms keep the previous interface
- Added graduate student schedule import: after completing the unified identity sign-in you can pull the graduate schedule directly, adjacent periods are merged into consecutive classes, single/odd-even weeks and week ranges are supported; if the direct connection fails an emergency web scraper is available
- Added a "Student Type" switch (first-launch wizard / Software Settings -> Student Type): switch between undergraduate and graduate identity, campus page features and schedule import entries are shown according to the identity, and switching does not affect saved schedules or custom settings
- Added graduate student grades: view course grades by semester, with grade statistics (course count, total credits, weighted average, pass rate)
- Added graduate training progress: shows training program information and credit progress for each course category (earned / required), lists the completed courses under each category, and shows courses outside the program separately
- Course editing supports custom picking of discrete weeks (such as skipped weeks or alternating weeks), and the discrete week display is applied consistently in schedule cards, details, the desktop widget and calendar export
- Added a native schedule widget on macOS: the widget can be placed on the Mac desktop and in Notification Center, with configurable color style, layout density and tomorrow's course display in "Software Settings"
- Added "Notifications and Reminders": enable pre-class reminders in Software Settings, customize the lead time (5 / 10 / 15 / 30 / 60 minutes, multiple selections allowed) and the do-not-disturb period, and check the currently scheduled reminders at any time. Reminder content follows the privacy setting - once "Show teacher name" is turned off, the teacher name is also hidden in lock screen notifications. Note: Android 14 and later do not grant the "Exact alarms" permission by default; without it reminders fall back to inexact wake-up and may be delayed by 9 to 15 minutes while the screen is locked
- Added Live Activity on iOS: during class you can see the current course and remaining time on the lock screen and in the Dynamic Island (requires iOS 16.1+, the Dynamic Island form requires iPhone 14 Pro or later)
- The schedule can now be exported as an image: the week you are viewing is rendered as a single complete image (including the weekday and date header), following your schedule appearance settings and current light or dark theme, unaffected by screen height or scroll position; afterwards you can save it to the photo library or share it (Android / iOS)
- Added "Dark mode" to Software Settings: choose Follow system / Light / Dark with immediate effect; each option comes with a miniature interface preview card, and the "Follow system" card shows both appearances side by side for comparison
- Added filters to the second classroom activity search page: filter by status (Subscribed / Available / Open for sign-up / Ongoing / Not started / Ended), credit hours, activity level and organizer; the filter button shows a badge when active, and applied conditions can be cleared at once above the list
- Added a recovery page when the app fails to start: it shows the error details and offers three actions - clear local settings, clear cache and clear app data (each with a confirmation dialog; afterwards local data such as schedules will be lost and need to be imported again)
- Widget entries are now available on iOS: "Widget" was added to Software Settings, and the first-launch wizard gained a widget guide page where the color style (colorful / monochrome), layout density and whether to show tomorrow's course can be configured
- The "User Agreement" and "Privacy Policy" entries on the About page are merged into a single "Legal" entry, where the privacy policy and support information can be read inside the app (previously the privacy policy opened an external web page); the layout of the user agreement, changelog and other documents has also been unified
- Fixed the desktop widget computing the week one week too early: teaching weeks now run from Sunday per the academic calendar, so in a semester starting on Monday (such as the 2026-2027 autumn semester) Sundays are no longer counted one week early, which made "tomorrow's courses" show "no classes tomorrow" on Saturday evening even though that Sunday does have classes
- Unified the in-app week numbering with the widget: the top bar, the calendar "Week N" badge and "Current week" in schedule settings all follow the Sunday-based rule, so Sundays in a Monday-start semester are no longer counted one week early (for example 2026-09-20 is now shown as week 4)
- Fixed the last day of the semester being one day late, which delayed the vacation check: with weeks running from Sunday, the last day of the final week is Saturday (2027-01-16 for the 2026-2027 autumn semester, so winter break starts on 1/17), whereas it was previously computed as 1/17, leaving the vacation page and the widget vacation state one day late
- Fixed the issue where repeatedly switching between repair categories could get stuck on a blank sub-item and tapping that blank item greyed out the screen (#326)
- Fixed the issue where "Study Plan Progress" stopped refetching after caching an empty result and always showed no data: it now keeps refetching automatically when the cache is empty (#345)
- Fixed the issue where a module (such as the campus page) that failed on its first fetch after sign-in stayed in the failed state: it now retries automatically after about 10 seconds; sign-in failures also no longer show only a generic message, but reveal the real reason and point out the night-time campus network restriction
- Fixed a possible crash when importing into an empty schedule for the first time: the schedule grid is now rendered only after the data is ready
- Fixed the iOS Live Activity (lock screen / Dynamic Island) not switching state and misjudging the "next class" for consecutive classes with the same name: two same-named classes on the same day now correctly switch to the second one, and a class inserted between periods 1-3 is no longer mistaken for the "next class"
- Fixed misjudged second classroom activity status: status is now determined by the sign-up period and the activity period, so the same activity can show both "Open for sign-up" and "Ongoing", and the search list of series activities is re-calibrated after sessions are fetched in the background instead of misjudging a series as "Not started"
- Updated the privacy notice to clarify the scope of campus service submissions, third-party web statistics and data cleanup, as well as the boundary that Live Activities are controlled by the system
- The "Volunteer Sichuan" entry on iOS now opens in the system browser, and an in-app privacy policy entry has been added
- The "Page transition animation" setting has been renamed to "Dock bar switch animation", and its description changed to "enable when switching functions by tapping the Dock bar"
- The second classroom activity list no longer shows star ratings (the detail page still does) and additionally shows the activity time period
- The iOS build is now prepared for App Store distribution (archiving, signing and the privacy disclosure questionnaire)
